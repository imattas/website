# Ian Mattas Portfolio

Personal portfolio and research site for Ian Mattas, built with AstroPaper.

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Posts and research notes live in `src/data/blog/` and `src/data/research/`. Draft entries stay out of the published site until their frontmatter `draft` value is set to `false`.
